# Organization Panel (Next.js + Material 3)

## Prerequisites

- Node.js 18+
- pnpm 10+

## Setup

```bash
cd ui/organization-panel
pnpm install
cp .env.example .env.local
pnpm dev
```

App runs at [http://localhost:3000](http://localhost:3000).

Backend API default: `http://localhost:8080` (`NEXT_PUBLIC_API_BASE_URL`).
