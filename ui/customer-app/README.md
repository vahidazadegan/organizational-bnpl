# Customer App (Next.js + Material 3)

## Prerequisites

- Node.js 20.9+
- pnpm 10+

## Setup

```bash
cd ui/customer-app
pnpm install
cp .env.example .env.local
pnpm dev
```

App runs at [http://localhost:3001](http://localhost:3001).

Backend API default: `http://localhost:8081` (`NEXT_PUBLIC_API_BASE_URL`).
